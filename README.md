# Voice_to_text_basic_project

Introduction :

I built a basic Voice-to-Text Conversion project using Python, SpeechRecognition, and PyAudio. This project converts spoken words into written text using a microphone.

The main purpose of building this project was to understand how voice recognition works and how Python can be used to convert human speech into text.

It is a simple beginner-level project where you can speak anything through your microphone, and the program recognizes your voice and displays the converted text on the screen.

Technologies Used :

- Python – Main programming language.

- SpeechRecognition – To recognize spoken words and convert speech into text.

- PyAudio – To access the microphone and capture audio input.

- VS Code – Used for writing and running the Python code.

How It Works :

1. The program accesses the microphone using PyAudio.

2. It listens to the user's voice input.

3. The SpeechRecognition library processes the captured audio.

4. The recognized speech is converted into text.

5. Finally, the converted text is displayed on the screen.

What I Learned :

- How speech recognition works in Python.

- How to capture voice input using a microphone.

- How to use the SpeechRecognition and PyAudio libraries.

- How to convert spoken words into written text.

- How to build and run a basic AI-related Python project.
